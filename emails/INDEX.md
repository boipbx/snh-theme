# SNH emails: index

59 emails · Shopify notifications: 15 · Klaviyo flows + campaigns: 44. Brand: ink #0E0E0E, the theme's brand orange #BF4512 (the current accent in Theme settings; #E0521C is the older, lighter orange and is only used decoratively), canvas #F6F4F1, cream tile #F5F2EC. Built with MJML (`emails/src`), compiled to inline-CSS HTML (`emails/dist`, 600px) + a plain-text version each. Rebuild: `cd emails && npm install && node build.js && node check.js && node docs.js`.

Paste the **HTML** file. Subject, preheader and the A/B subject are below (and in `manifest.json`). Gallery: `emails/preview/index.html`.
