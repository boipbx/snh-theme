# Sunday ONLINE SiS deal codes

**The deal:** 15% off **Science in Sport (SiS)** products, **online, Sundays only**. The Saturday SiS deal is in-store only and has no online code.

**Settings for every code:**
- **Applies to:** the collection *SCIENCE IN SPORT | SiS* (id 453152768254, handle `sis`).
- **Valid:** Sunday 00:00–23:59 Sri Lanka time.
- **Customers:** all; no minimum; unlimited uses.
- **Combining:** combines with no other discount.

The site builds the day's code from the date (SUN15-DDMON). The "Sunday SiS deal" chip/wheel reveals it and applies it to the cart.
